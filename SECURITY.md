# Security Policy

This repository is for education and demonstration. Code under `learn/` is deliberately simple and must not be used to protect real data.

## Reporting a vulnerability

If you find a flaw in a showcase app (for example a misuse of a library, a broken test, or a claim in the docs that is wrong), please open a private report through GitHub's **Security → Report a vulnerability** tab rather than a public issue.

Please include the app, the commit, and steps to reproduce. Expect an acknowledgement within a week.

## Scope

- In scope: anything in `apps/`, CI configuration, and the accuracy of the docs.
- Out of scope: issues in upstream libraries (report those to the library), and code under `learn/` that is insecure on purpose and labeled as such.
